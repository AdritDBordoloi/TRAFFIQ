## 6. Architecture & Subsystem Highlights

### A. Adaptive Signal Controller (`traffiq.enforcement.adaptive_signal`)
- **Queue-Proportional Timing**: Dynamically computes green phase duration between configurable bounds (`min_green=5.0s`, `max_green=45.0s`) weighted by real-time approach vehicle density.
- **Emergency Vehicle Preemption**: Preempts normal cycle within $<100\text{ ms}$ upon ambulance detection, forces conflicting approaches through an all-red clearance phase (`all_red=2.0s`), holds green corridor for the designated approach, and safely restores normal cyclic operation upon exit line clearance.
- **Starvation Prevention Aging**: Tracks approach waiting time to prevent heavy-traffic approaches from permanently starving low-density approaches.

### B. Four-Way Intersection Processor (`traffiq.vision.four_way`)
- **Spatial Quadrant Mapping**: Partitions single 1280x720 panoramic / fisheye feeds into 4 quadrants (North, South, East, West) or ingests 4 independent approach streams.
- **Per-Approach Tracking**: Coordinates ByteTrack tracking and count metrics across all 4 quadrants independently.
- **Integrated HUD Compositing**: Renders dynamic signal state indicators (Red/Yellow/Green badges), vehicle counts, and queue statistics onto each quadrant in real time.

### C. Web Dashboard (`traffiq.web` & `frontend/`)
- **REST Telemetry API**: Exposes `/api/status`, `/api/counts`, `/api/violations`, `/api/emergency/trigger`, and `/api/controller/cycle`.
- **Multipart MJPEG Live Stream**: Serves `/video_feed` with high-efficiency JPEG compression (`quality=65-70`).
- **Modern Dark ITS Frontend**: Single-screen responsive dashboard with real-time telemetry polling, manual signal cycle override, ambulance priority trigger, and printable e-challan inspection modal.
- **Standalone Launcher**: `python run_dashboard.py --host 0.0.0.0 --port 5000` boots the server in one command.

## 7. Operational Recommendations for Deployment

1. **Production Video Inputs**: When connecting USB 3.0 / DirectShow webcams or RTSP security cameras, use `CameraStream(source=..., threaded=True)` to decouple network/USB capture delays from the inference loop.
2. **GPU Deployment**: Ensure CUDA 12.x drivers and PyTorch with CUDA support are installed; `torch.backends.cudnn.benchmark = True` and `torch.inference_mode()` should remain enabled in `VehicleDetector`.
3. **Database Maintenance**: The SQLite database `traffiq_enforcement.db` operates in WAL (Write-Ahead Logging) mode; periodic vacuuming or archiving of `challan_records` can be scheduled after 100,000+ entries.
4. **Git Index Management**: `.gitignore` is now configured with strict exclusions for video uploads (`uploads/`), model weights (`*.pt`), databases (`*.db`), and test violation receipts (`violations/`). Keep these patterns intact to prevent repository bloat.
